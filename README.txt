هرمیتاژ - سفارش‌های اختصاصی هر مشتری

محتویات: index.html و worker.js

نصب: هر دو فایل را در ریشه مخزن GitHub جایگزین کنید و منتظر Deploy موفق Cloudflare بمانید. نیازی به اجرای schema.sql یا تغییر دیتابیس نیست؛ از جدول orders و customer_id موجود استفاده می‌شود. متغیرهای ADMIN_USERS و SESSION_SECRET را تغییر ندهید.

امنیت: سفارش‌ها در حساب هر مشتری فقط با نشست معتبر همان مشتری نمایش داده می‌شوند. فهرست سفارش‌های عمومی صفحه اصلی و API عمومی آن حذف شده است. سفارش‌های مهمان در حساب مشتری نمایش داده نمی‌شوند و فقط در پنل مدیر قابل مشاهده‌اند.
