# هرمیتاژ — نسخه پنل مدیریت با ورود محدود مدیران

این نسخه، ظاهر و قابلیت‌های فعلی فروشگاه را حفظ می‌کند و پنل مدیریت را به API سمت سرور وصل می‌کند. احراز هویت در Worker انجام می‌شود؛ اطلاعات مدیرها داخل فایل HTML یا مخزن GitHub قرار نمی‌گیرد.

## فایل‌ها
- `public/index.html` فایل سایت
- `worker.js` API ورود مدیر و ذخیره محصولات/اسلایدر
- `schema.sql` ساخت جدول D1
- `wrangler.toml` تنظیمات استقرار

## راه‌اندازی Cloudflare
این بسته نیاز به **Cloudflare Workers + D1** دارد. ZIP را مستقیماً به‌عنوان سایت ایستا در Pages آپلود نکن؛ باید Worker با تنظیمات زیر مستقر شود.

1. در Cloudflare برو به **Workers & Pages → D1 SQL Database → Create database** و نام `hermitage-db` را انتخاب کن.
2. در دیتابیس، بخش **Console**، محتوای `schema.sql` را اجرا کن.
3. شناسه دیتابیس را کپی کن و در `wrangler.toml` به‌جای `PASTE_D1_DATABASE_ID_HERE` قرار بده.
4. پروژه را در یک محیط دارای Wrangler با دستور `npx wrangler deploy` مستقر کن. قبلش `wrangler.toml` را با شناسه واقعی دیتابیس تکمیل کن.
5. در تنظیمات Worker بخش **Settings → Variables and Secrets** این دو مقدار را به‌صورت Secret اضافه کن:
   - `SESSION_SECRET`: یک رشته تصادفی طولانی و محرمانه (حداقل ۳۲ کاراکتر).
   - `ADMIN_USERS`: آرایه JSON حساب مدیرها، نمونه: `[ {"username":"nima","password":"رمز-قوی-و-منحصربه‌فرد"} ]`
6. در Worker باید D1 binding با نام دقیق `DB` و Assets binding با نام دقیق `ASSETS` فعال باشند؛ فایل `wrangler.toml` این bindingها را تعریف می‌کند.

## امنیت و امکانات
- فقط حساب‌هایی که در Secret با نام `ADMIN_USERS` تعریف شده‌اند وارد می‌شوند؛ ثبت‌نام عمومی وجود ندارد.
- ورود و اعتبار نشست سمت سرور بررسی می‌شود؛ نشست پس از ۸ ساعت منقضی می‌شود.
- دکمه خروج، نشست مرورگر را پاک می‌کند.
- محصولات و اسلایدها در D1 ذخیره می‌شوند و برای همه بازدیدکنندگان یکسان‌اند.
- برای افزودن مدیر، فقط آرایه `ADMIN_USERS` را در Secret ویرایش کن؛ رمزها را در کد یا GitHub ننویس.
- تصاویر فعلی در داده محصول ذخیره می‌شوند؛ محدودیت بارگذاری هر عکس در رابط سایت ۱.۲ مگابایت است.
- سبد خرید فعلاً محلی است. ثبت سفارش و پرداخت آنلاین هنوز پیاده‌سازی نشده‌اند.

## نکته مهم
این نسخه کد آماده است اما تا وقتی D1 ساخته و Worker با Secrets مستقر نشود، ورود مدیر فعال نخواهد شد. از رمز واقعی و تکراری استفاده نکن.
