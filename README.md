# HERMITAGE | هرمیتاژ

نسخه بهبودیافته فروشگاه با اسلایدر خودکار، پنل مدیریت محصولات، آپلود عکس، توضیحات، قیمت، دسته‌بندی، جست‌وجو و سبد خرید.

## انتشار روی Cloudflare Pages
فایل `index.html` را در ریشه مخزن GitHub قرار بده و Cloudflare Pages را به همان مخزن وصل کن. Build command خالی و Output directory برابر `.` باشد.

## نکته مهم
این نسخه فعلاً فرانت‌اند است. محصولات، عکس‌ها و سبد خرید در localStorage همان مرورگر ذخیره می‌شوند؛ بنابراین بین دستگاه‌ها مشترک نیستند و پنل مدیریت هنوز رمز ورود امن ندارد. ثبت سفارش سروری و پرداخت واقعی هم هنوز وصل نشده‌اند. برای فروش واقعی باید بک‌اند، دیتابیس و احراز هویت اضافه شود.
