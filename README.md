# HERMITAGE | هرمیتاژ
نسخه اولیه فروشگاه استاتیک و واکنش‌گرا.

## انتشار روی GitHub
1. فایل `index.html` را در ریشه مخزن `hermataje` آپلود کن.
2. Commit changes را بزن.
3. در Cloudflare Pages مخزن GitHub را متصل کن و Build command را خالی بگذار؛ Output directory را `.` قرار بده.

## توجه
این نسخه نمونه اولیه است. سبد خرید و تغییرات پنل مدیریت در localStorage همان مرورگر ذخیره می‌شوند. ورود امن مدیر، دیتابیس مشترک، ثبت سفارش واقعی و پرداخت آنلاین هنوز پیاده‌سازی نشده‌اند.
